# Pictures still needed for blog posts

Each post below shows a plain placeholder until you add a picture. To add one:

1. Save the picture in `content/photos/` (a `.jpg`, for example `my-picture.jpg`).
2. Add one line for it in `content/photos/photos.json` with a short description of what the picture shows (`"my-picture": {"alt": "..."}`).
3. In the post file in `content/blog/`, delete the `image_todo:` line and add `image: my-picture` under the date.

Company posts need your own photos. For the technology posts, use a picture you are allowed to use (for example from Wikimedia Commons, with the credit it asks for, or one you took yourself). Please avoid computer-generated pictures.
