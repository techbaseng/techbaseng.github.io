# content

The text and data of the site. Each course has its own folder named after its web address (for example `techbase-css`), holding `course.json` (page text and the ordered lesson list) and a `lessons` folder with one HTML file per lesson. `site.json`, `courses.json` and `paths.json` hold site-wide details. See [../docs/CUSTOMIZING.md](../docs/CUSTOMIZING.md).
