In February 2025, AI researcher Andrej Karpathy used the phrase "vibe coding" for a style of programming where you describe what you want in plain language, let an AI tool write the code and mostly steer by running it and asking for changes. The phrase spread quickly.

## What it is good for

- **Prototypes and personal tools.** A quick page, a small script or a game idea can appear in minutes.
- **Learning by example.** Seeing working code for something you described can show you how it fits together.
- **Lowering the barrier.** People with an idea but little experience can try things.

## Where it goes wrong

- **Hidden mistakes.** Code that runs may still be wrong, slow or unsafe.
- **No understanding.** When something breaks, someone has to find out why.
- **Security.** Generated code can include weaknesses, such as storing passwords badly, that a beginner would not notice.

## Our view

AI assistants make strong programmers faster, and they can help beginners explore. But a learner who has never written a loop, read an error message or debugged a program cannot tell good output from bad. That is why we teach the fundamentals first, then bring in AI tools as helpers, and why every project is tested and explained by the learner.

Think of it as learning to drive before using cruise control.
