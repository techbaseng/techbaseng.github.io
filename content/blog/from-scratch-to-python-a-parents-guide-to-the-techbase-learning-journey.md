Parents often ask the same question: "Yes, but what exactly are they learning to do?" It is a fair one. Coding covers everything from dragging coloured blocks to building machine learning models. Here is how the Techbase learning path is organised, one stage at a time.

## Stage 1: Scratch (ages {ages:techbase-scratch})

Scratch comes from MIT and is where almost every Techbase learner begins. Programs are built by connecting coloured blocks, so no typing is needed. The blocks stand for real programming ideas: loops, conditions, variables and events, presented like puzzle pieces.

![Girls build a Scratch project together at a laptop.](photo:girl-day-scratch)

By the end of the Scratch course, a learner can make their own games, animations and small interactive stories. More importantly, they understand the logic underneath: *if this happens, do that; repeat until a condition is met; when the user clicks, start this sequence.*

This is not a toy. These children are programming, in a form that does not depend on fast typing.

## Stage 2: HTML and CSS (ages {ages:techbase-html})

Once the logic feels familiar, learners move to the two languages behind every website: HTML for structure and CSS for appearance. Someone who finishes both can build a styled, multi-page website and understands how the sites they visit are put together.

The Techbase [HTML course](../../techbase-html/index.html) has 34 lessons. The [CSS course](../../techbase-css/index.html) has 73, the biggest in the series, because styling the web has real depth. Along the way learners meet responsive design, Flexbox layout and animation.

## Stage 3: JavaScript (ages 10 and up)

JavaScript makes a website interactive: forms that check themselves before sending, content that changes without reloading the page, and data pulled in from the internet. The [46-lesson course](../../techbase-js/index.html) covers the whole language, including modern features such as async/await and ES6 modules.

## Stage 4: Python (ages 10 and up, no prerequisites)

Python is widely used for data science, machine learning, automation and the back end of web applications, and it is also very readable for beginners. The [45-lesson Python course](../../techbase-python/index.html) moves from variables and loops to NumPy, Pandas and an introduction to machine learning ideas. Learners who finish are working at an intermediate to advanced level.

![A student concentrates on a coding exercise in a Techbase class.](photo:bmhs-student-focus)

## What it looks like in real life

Ivan Ahonkhai started with Scratch and has since worked through HTML, CSS, JavaScript and Python, where he is already at an intermediate level and can confidently explain his projects. That confidence helped his readiness for scholarship interviews that assessed both academic and non-academic skills. His younger brother David showed an early interest in technology and began exploring Scratch on his own before he turned six.

That is not unusual for children who start young and follow a structured path. What makes the difference is consistency: a regular weekly session, a clear curriculum and an instructor who knows when to push and when to consolidate.
