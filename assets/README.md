# assets

Files copied unchanged into the website. `css/app.css` has the design tokens and shared parts, `css/site.css` the company pages, `css/lesson.css` the lessons. `js/app.js` runs site-wide features, `js/site.js` the company pages, `js/auth-ui.js` the login and account pages and `js/lesson.js` lesson interactivity. `js/auth.js` is **not** stored here: it is built from `src/auth/` during every deployment. `fonts/` holds the self-hosted fonts (SIL Open Font License) and `img/` the logo, icons and partner logos.
